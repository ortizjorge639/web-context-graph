How it works

Think in branches.
Stay in flow.

01

Responses become ideas you can act on.

Agent output is split into meaningful, replyable chunks—not a monolithic wall of text. Pick the exact premise, recommendation, or question you want to pursue.

02

Reply there. A new branch opens.

The original thread stays intact. Your follow-up starts a child conversation from that precise response chunk, with its relationship recorded on both sides.

03

Each branch remembers only its lineage.

A branch inherits the path from root to current—never its siblings. Experiments stay focused, competing directions stay clean, and context remains explainable.

Working software, open source

A real MVP you can inspect today.

The current build combines a FastAPI backend, a React workspace, GitHub Copilot CLI, and a plain-file vault—running locally on your machine.

Where it is today

Purposefully local.
Built for one curious mind.

Web-Context Graph is an early single-user MVP, not a hosted service. It runs on localhost, uses your authenticated Copilot CLI, and keeps data on your machine.
